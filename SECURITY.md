# Security Policy

## Supported version

Version 1.0.0 is supported. Earlier versions are not supported.

## Reporting

Use GitHub private vulnerability reporting when enabled. Do not open public issues containing certificates, private keys, cookies, account data, raw memory dumps, full settings files, or unsanitized logs.

Allium can request administrator approval, install dependencies and fonts, set CurrentUser execution policy to `Unrestricted`, write local Roblox configuration, operate on a Roblox process when memory features are enabled, create local certificate material for HTTPS interception, and monitor local files and processes through the watchdog.
